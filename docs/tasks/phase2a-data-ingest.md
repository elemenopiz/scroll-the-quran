# Phase 2a-data — Ingest Quran text, translations, and fonts (scripts only, no Swift)
Owns: `Tools/content-gen/ingest-*.mjs`, `Tools/content-gen/out/**` (committed), `Tools/content-gen/ATTRIBUTION.md`, `Tools/content-gen/package.json` (no runtime deps beyond Node 24 built-ins).
Does NOT touch `Content/`, `Packages/`, `App/` (Phase 1 owns those right now). The orchestrator copies `out/` into `Content/quran/` after Phase 1 merges.

Deliver in `Tools/content-gen/out/quran/`:
1. `arabic-uthmani.json` — flat array of 6,236 strings, Tanzil Uthmani text. Fetch with `curl -s -X POST https://tanzil.net/pub/download/download.php -d 'quranType=uthmani&outType=txt&agree=true'` (or `marks=true` variant) and parse `sura|aya|text` lines; fall back to `https://cdn.jsdelivr.net/gh/fawazahmed0/quran-api@1/editions/ara-quranuthmanihaf.json`. Every entry must contain Arabic script. Keep pause marks. Note the exact source in ATTRIBUTION.md (Tanzil CC BY 3.0, verbatim).
2. `itani.json`, `saheeh.json`, `ruwwad.json`, `pickthall.json` — flat 6,236-string arrays. Itani + Pickthall from fawazahmed0 CDN (`eng-talalitani`, `eng-mohammedmarmadu`); Saheeh + Ruwwad from QuranEnc `https://quranenc.com/api/v1/translation/sura/{english_saheeh|english_rwwad}/{1..114}` (fields `translation`, strip footnote markers like `[1]` and HTML, keep the footnote text out). Be polite: sequential requests, 150 ms delay, retry 3×. No Arabic script in any translation entry; no empty entries.
3. `surahs.json` — 114 objects `{number, name, meaning, ayahCount, revelation ("makki"|"madani"), startIndex, juz:[..], pages:[first,last]}` derived from Tanzil `https://tanzil.net/res/text/metadata/quran-data.xml` (suras, juzs, pages). Verify `startIndex` monotone, sum of ayahCount = 6236, `2:255` → global index 261.
4. `translations.json` registry: `[{id, abbrev, name, translator, language:"en", copyright, attribution, license, file, isDefault, offline:true}]` with exact strings: Itani "Translation by Talal Itani, ClearQuran.com" (CC BY-ND 4.0, abbrev "CLEAR"), Saheeh International via QuranEnc (attribution "Saheeh International, via QuranEnc.com" + version from API, abbrev "SAHEEH"), Ruwwad Translation Center via QuranEnc (abbrev "RUWWAD"), Pickthall (public domain, abbrev "PICKTHALL"). Itani is default.
5. `Tools/content-gen/out/fonts/`: KFGQPC Uthmanic Hafs v18 TTF (`https://verses.quran.foundation/fonts/quran/hafs/uthmanic_hafs/UthmanicHafs1Ver18.ttf`, or https://github.com/nuqayah/qpc-fonts) + its license text; Amiri Regular/Bold (https://github.com/aliftype/amiri/releases, OFL) as fallback + OFL.txt. Print the PostScript/family names (`fc-scan` or `python3 -c "from fontTools..."` if available, else `strings | grep -i hafs`).
6. `ingest-translations.mjs --verify` re-validates everything above from disk and exits non-zero on any violation; `--fetch` downloads. `npm test` (plain `node --test`) covers the parsers with tiny fixtures.
DoD: `node Tools/content-gen/ingest-translations.mjs --verify` exits 0 and prints the counts; ATTRIBUTION.md lists every source with licence + URL + fetch date; commit sizes (expect ~1 MB per translation, ~1.5 MB Arabic, fonts ~1–2 MB).

# Phase 3a — The Quran tab (reader)
Owns: `Packages/ScrollKit/Sources/FeatureReader/**`, `Tests/FeatureReaderTests/**`, `UITests/Specs/reader-*.json`, `UITests/ReaderTests.swift`. Simulator: use ONLY the device named `ScrollSim-3a` (boot it; never "booted").
References: `reader-dark.png`, `translation-sheet.png`, `notes-sheet.png` (+ light appearance derived from tokens).

Build `ReaderView(surah:startAyah:)`: per-surah vertical paging (`ScrollView` + `LazyVStack(spacing:0)` + `.scrollTargetBehavior(.paging)` + `.scrollPosition(id:)` + `.containerRelativeFrame(.vertical)`), page 0 = centered logo card (rounded dark square with the line mark), then one `VersePage` per ayah using DesignSystem `VerseText` (muted Arabic above English) with size tiers and `VersePaginator` continuation pages ("(1/3)" in the reference line). Chrome: top-left `CapsuleIconGroup` [dice random, heart like] + translation pill (abbrev, opens `TranslationSheet`), top-right bookmark pill + surah pill "Al-Baqarah ▾" (opens `SurahPicker` with a searchable list + juz sections); left `VerseRail` (dashed line, solid current indicator with number, last number at bottom, tap/drag to jump with haptic ticks); right action stack heart / comment (→ `NotesSheet` autosaving via UserStore) / share (→ `ShareSheet` rendering a share card with `ImageRenderer`); `ToastHint("Tap or slide", "to jump to any verse")` with dismiss, shown once (Prefs). Auto-advance to next surah at the end (Bismillah handling: show as a muted line on page 0 for surahs other than 1 and 9). Marks verse read after 1.2 s dwell; restores `lastReaderPosition`. Random verse (dice) picks uniformly over 6,236.
Tests: size-tier selection, dwell logic, rail position math, random distribution sanity; UI tests: 3 swipes → ayah 3, rail drag to 80% → round(0.8·N), translation switch changes text, note persists after relaunch; performance: surah 2 opens < 400 ms (`XCTClockMetric`).
DoD: snapshots `reader-dark reader-light translation-sheet notes-sheet` < 0.10 (notes-sheet 0.12); `Tools/verify.sh --ui --snap …` exits 0.

# Phase 2b-scripts — Deep Study generation pipeline (Node only, no Swift yet)
Owns: `Tools/content-gen/{segment-passages,themes,build-requests,submit-batch,poll-batch,validate,assemble,judge-sample}.mjs`, `Tools/content-gen/schema/**`, `Tools/content-gen/prompts/**`, `Tools/content-gen/named-passages.json`, `Tools/content-gen/discover-seed.txt`, `Tools/content-gen/out/study/**`, `Tools/content-gen/out/themes.json`, `Tools/content-gen/out/discover.json`, `Tools/content-gen/README.md`. Package deps allowed: `@anthropic-ai/sdk`, `ajv` (commit `package.json` + lockfile; `node_modules` ignored).
Does NOT touch `Content/`, `Packages/`, `App/`. Coordinate file formats with `docs/tasks/phase2b-study-pipeline.md` and the plan's "Content-generation pipeline" and "Key types" sections — the Swift side (StudyContent) is a later task that will decode exactly what you emit.

Inputs: use `Tools/content-gen/out/quran/*.json` if the 2a-data task has landed in your worktree; otherwise download Itani + Arabic yourself into `work/` (gitignored) using the same CDN URLs as `docs/tasks/phase2a-data-ingest.md`.

Load the `claude-api` skill before writing any API code (current model ids, Message Batches API, structured outputs / JSON schema output, prompt caching, pricing). The key is in `~/.zshrc` as `ANTHROPIC_API_KEY`; source it in a subshell for real calls, never print it, never commit it.

Deliver:
1. `segment-passages.mjs` → `out/study/passages.json` (ayah key → unit key) + `work/units.jsonl`; rules per plan (≥12 words own unit; merge shorter neighbours ≤5 ayat/≤60 words; never across surah; `named-passages.json` protected). Print unit count (expect ~3,000–3,400).
2. `themes.mjs` → `out/themes.json` with ≥ 40 themes `{id, title, refs:["2:155-157",…], blurb}` — from QUL Ayah Themes (https://qul.tarteel.ai/resources/ayah-theme/62; download JSON/SQLite if a download link exists, record its terms) else a hand-curated, well-known list (Patience in Trials, Gratitude, Mercy of God, Trust in God, Forgiveness, Prayer, Charity, Family, Justice, Knowledge, Death & the Hereafter, Paradise, Creation, Prophets, Repentance, Hope, Fear & Hope, Humility, Honesty, Community, Guidance, Light, Dua, Ramadan, Hajj…).
3. `schema/study.schema.json` = `{ key, surah, start, end, theme, themeId, title, tier, meaning, historicalContext, keyTerms:[{arabic, gloss, note}], lifeInProphetsTime, didYouKnow, theologicalSignificance, crossReferences:[{ref, why}], applyIt, exploreFurther:[ref], meta:{model, promptVersion, generatedAt, reviewed} }` with word-count bounds as in the plan. `keyTerms[].arabic` MUST be Arabic script (no transliteration field exists); English prose fields must not contain Arabic script.
4. `prompts/system.md` (cached system prompt: accessible, mainstream, non-sectarian summaries grounded in Ibn Kathir / al-Tabari / al-Qurtubi / al-Sa'di; "scholars differ" when they do; no fatwas/legal rulings; asbab al-nuzul only when attested; honorific "the Prophet Muhammad (peace be upon him)" once; second-person `applyIt`; refs within bounds) and `prompts/user.hbs`-style template (surah meta, unit English + Arabic text, ±3 ayat context, theme hint, optional tafsir excerpt).
5. `build-requests.mjs` (`--model claude-opus-5` default, `--only discover|all|surah:N`, `--dry-run` prints request count + estimated input/output tokens + $ using the skill's pricing; cache dir `work/cache/`; `custom_id = p1:<model>:<key>`; structured JSON output via the schema).
6. `submit-batch.mjs`, `poll-batch.mjs`, `validate.mjs` (ajv + rules), `assemble.mjs` (→ `out/study/surah_NNN.json` sorted keys; `out/discover.json` from `discover-seed.txt` of ~300 keys you curate: iconic, comforting, frequently-shared ayat across all juz), `judge-sample.mjs` (rubric scoring with Opus; `--sample 0.05`).
7. Run for real: `--only discover` (≈300 units) after `--dry-run` shows < $15; wait for the batch, validate, assemble. Do NOT run `--only all` (the orchestrator triggers that later). If the key is unavailable, stop after dry-run and say so.
DoD: `node segment-passages.mjs` prints the count; `node build-requests.mjs --dry-run --only discover` output pasted; `node validate.mjs out/study` exits 0 on the generated Discover shards; `out/discover.json` keys all resolve to generated units; README documents every command.

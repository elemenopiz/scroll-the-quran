## Amendment (owner, 2026-09-12, with screenshots of the original mid-scroll): FIXED SLOTS
"When you scroll the verses on the original app all of them have the same placement and look polished; on ours it's not the case." The original's cards are the **same height with the same slots on every card**, so the pager lands identically each time: previous card's action row visible above, next card's top edge below, the theme chip always at the same y.
- Make the card a fixed-height layout on the 402×874 pt canvas: reserve slots — chip; title (1 line, `minimumScaleFactor` 0.8 for long surah names); translation label; **Arabic slot fixed at 2 lines** (accent size down to the 13 pt floor to fit 2 lines, else omit the text but keep the slot); **quote slot fixed at 4 lines** (`lineLimit(4)` with the same "…" the meaning uses, text vertically centred in the slot when shorter); meaning label; **meaning slot 4 lines**; **did-you-know box 3 lines**; cross-ref chips row (1 row, max 2 chips); "Deep study ›"; action row. Slot heights come from the font metrics at the default content size; under Dynamic Type the slots scale with the fonts (4d) and the card may grow, which is acceptable.
- Result: every Discover card has identical geometry; the first card's chip sits at the reference's y; scrolling shows the previous card's action row and the next card's top exactly as the original does (measure from `Reference/discover-dark.png`: card top ≈ 14 % of the screen height, card bottom ≈ 85 %).
- A unit test lays out all 326 Discover units and asserts every card height is equal.
- The translation label now reads `ITANI` (was `CLEAR`); the registry changed on main, so expect it in captures.

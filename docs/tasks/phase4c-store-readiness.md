# Phase 4c — App Store readiness
Owns: `App/PrivacyInfo.xcprivacy`, `Config/**` (Release settings, `Local.xcconfig.example`), `project.yml` (only for archive/export settings and the privacy manifest), `docs/store/**` (metadata, screenshots plan, review notes), `Tools/release/**` (archive + export scripts), `App/Info.plist` (version/build, export compliance key), `.github/workflows` not needed.
Deliver:
1. `PrivacyInfo.xcprivacy`: no tracking, no collected data (all state on device), required-reason APIs actually used (UserDefaults / file timestamps if any).
2. Release config: bitcode n/a, `SWIFT_OPTIMIZATION_LEVEL=-O`, strip symbols, `MARKETING_VERSION=1.0.0`, `CURRENT_PROJECT_VERSION=1`, `ITSAppUsesNonExemptEncryption=false`.
3. `Tools/release/archive.sh` (`xcodebuild archive` for `generic/platform=iOS` with `DEVELOPMENT_TEAM` from `Config/Local.xcconfig`, `-allowProvisioningUpdates`) and `export.sh` (`-exportOptionsPlist` for `app-store-connect` method) + `upload.sh` (`xcrun altool`/`notarytool` equivalent: `xcrun altool --upload-app` or `xcodebuild -exportArchive` with upload). They must run end-to-end up to the signing step without a team id and fail with a clear message at signing.
4. `docs/store/metadata.md`: name "Scroll the Quran", subtitle, promotional text, description (disclosing AI-assisted study notes and the classical sources), keywords, support URL placeholder, privacy policy text (device-only data, StoreKit, no analytics), age rating answers (4+), category Books / Reference, review notes (demo: no login required; Sign in with Apple optional; test the paywall with sandbox), in-app purchase display names + descriptions for the 3 SKUs and the subscription group, and the exact App Store Connect click-path the user must follow (create app record with bundle id `com.quranscroller.app`, create subscription group "Premium", the three products with the intro offers, App Privacy answers, agreements).
5. `docs/store/screenshots.md` + `Tools/release/screenshots.sh`: capture the 6.9" and 6.5" App Store screenshot sets from the simulator via the `--screenshot` routes with marketing framing (use the `PhoneFrame` asset and short captions), output to `docs/store/screenshots/`.
6. Run `axiom:security-privacy-scanner`, `axiom:accessibility-auditor`, `axiom:iap-auditor` agents and fix what they find within your ownership; list the rest.
DoD: `Tools/release/archive.sh` reaches the signing step (or completes if a team id is configured); `xcodebuild -exportArchive` dry-run validated; privacy manifest present in the built app; metadata + screenshots committed; auditor findings addressed or listed.
